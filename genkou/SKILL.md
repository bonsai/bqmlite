# genkou — 90秒×N エージェント原稿ジェネレーター

9人のエージェントが同じテーマでそれぞれ90秒（約800〜1100字）の原稿を書く。各エージェントは固有の文体・視点・比喩で、テーマを再解釈する。

## 使い方

1. テーマとエージェントリストを受ける
2. 既存原稿（`.skills/genkou/`）をコーパスとして参照
3. 各エージェントの文体ルールで90秒の原稿を生成
4. 出力: `genkou/YYYY-MM-DD-<テーマ>-<agent>.md` または既存ファイルの上書き

## 文体ルール（各エージェント）

### 寺山修司
- 身体・感覚・胸キュン・踊る・爆発する
- 鏡・影・追跡・追われる
- 確率を数値ではなく感情のメタファーに
- 語尾: 「〜になる」「〜する」「〜ない」

### 村上春樹
- 日常の中の不気味さ、井戸、電話、猫
- 数の反復（99本、101本目、12%の確率）
- 受話器を置く、光を灯す、静かな行動
- 語尾: 「〜だ」「〜た」「〜かもしれない」

### フランク・ザッパ
- 音楽理論（拍子、ビート、小節）
- 間違った音符から生まれる音楽
- タイミングの不可能性を可能にする
- 語尾: 「〜だ」「〜弾く」「〜生まれる」

### 平賀源内
- 漢文口調「是れ〜なり」「附け」「名づく」
- 発明プロセスの説明（本を読んで→試して→失敗して→なおして）
- 高空奇談・潜水の術・大筒模型のオマージュ
- 語尾: 「〜なり」「〜なり」「〜也」

### 志賀直哉
- 簡素・淡白・確認の繰り返し
- 「多い」「必要はあるのか」「それでいい」
- 静かな部屋、座っているだけ
- 語尾: 「〜だ」「〜だけだ」「〜いい」

### 宮沢賢治
- 銀河・星・粒子・雨・風
- 仏教的慈悲「皆が幸せにならぬうちは」
- 星の軌道、小惑星、破片
- 語尾: 「〜だ」「〜微笑む」「〜動く」

### ダダイスト
- ノイズ・不合理・意味の相対化
- 「誰が言った？」「半分半分」
- 爆発・破壊・破片
- 語尾: 「〜だ」「〜笑う」

### ドラッカー
- 組織・効率・検証・スコアリング
- 「効果的」「管理」「改善」
- 現実の課題、SFではない
- 語尾: 「〜だ」「〜変わる」「〜必要だ」

### bons
- 短文・体言止め・技術用語羅列
- 「繋ぐ」「全部つなぐ」「繋ぐのが本丸」
- 部品名を羅列（MediaPipe、3dgs-gws、Jev）
- 語尾: 「〜つなぐ」「〜だ」「〜で」

## 生成手順

```
1. テーマを受領（例: "MediaPipe×3DGS×Jev"）
2. エージェントリストを受領（例: [terayama, murakami, 源内, bons]）
3. コーパス .skills/genkou/ を参照（文体確認用）
4. 各エージェントで原稿を生成:
   a. テーマをそのエージェントの視点で再解釈
   b. 90秒分（約800〜1100字）を生成
   c. ファイル名: `90sec-<agent>.md`
5. 出力先: `.skills/genkou/` または指定パス
```

## ファイルフォーマット

```markdown
# 90秒×N — <エージェント名>原稿

## <タイトル>

<本文 800〜1100字>
```

## テーマの例

- MediaPipe × 3DGS × Jev（既存）
- 鏡の間（空間記憶装置）
- 風船とガウス（浮遊表現）
- 潜水と判定（水底の判断）
- 大筒と判定層（砲弾のような判定）

## 注意事項

- 各原稿は**90秒読み上げる**ことを想定（約800〜1100字）
- 既存エージェントの文体を尊重し、矛盾しない
- テーマは共通だが、視点・比喩・語尾はそれぞれ独立
- コーパス（既存原稿）は参考にするが、同じ表現を再利用しない
- 生成後のコミットは `genkou: <テーマ> — <エージェント>` の形式
