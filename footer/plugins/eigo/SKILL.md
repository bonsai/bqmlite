# eigo（英語コーナー / footer プラグイン 1）

## 目的 / What it does

フッターの **最初のブロック**。英語学習の仕組みを 1 節に束ねる。

- **語彙ハイライト**: `vocab-highlight` スキル（本文中の難語を **太字**＋和訳）
- **Tips 単語コーナー**: `tips-word` スキル（ドメイン用語を 1〜2 語）

## いつ適用するか / When

- footer マネージャーから呼ばれたとき、または単体で「英語コーナー」系の発言があったとき。

## 手順 / Process

1. まず `vocab-highlight/SKILL.md` と `tips-word/SKILL.md` を参照する。
2. 本文中の難語ハイライトは **本文内** に出す（変更なし）。
3. フッターでは **Tips 単語コーナー** を 1 節として表示。

## フォーマット / Format

```text
### Tips 単語 🔎
- **[IT] idempotent** = 冪等（何度実行しても同じ結果になる性質）
```

## ルール / Rules

1. 表示は 1 節のみ。本文内ハイライトとは別枠（既存ルールと同じ）。
2. ドメインローテーション、1〜2 語上限は `tips-word` に従う。
3. コード・識別子・パスは対象外（原文のまま）。

## 注意 / Caveats

- このスキルは「まとめ役」。実処理の責任は vocab-highlight / tips-word にある。
