# 90秒×9 — 平賀源内原稿

## 是れ新しき鏡の間なり

是れは新しき機械なり。人の前に鏡を据え、鏡に眼を附け、眼に心を附け、心に空間を附け、空間に記憶を附ける。人の手が伸びる。鏡の眼が手の先を読む。四六十八点の数値が紙に落ちる。紙が火に燃える。数値が煙となり、煙が部屋を満たす。部屋の形が生まれ、形がガウスとなり、ガウスが数万に増え、数万が空間となり、空間が記憶する。人が動き、動きが記憶され、記憶が判断し、判断が次に人を動かす。是れを鏡の間と名づく。高空奇談は空に飛び、此れは空間に眠る。空は飛ぶが、空間は座して動く。座して動くとは、動く人の為に空間が動く事なり。人は驚く。鏡が動いたと。鏡は動いていない。人の為に出て来たのだ。是れが発明なり。
