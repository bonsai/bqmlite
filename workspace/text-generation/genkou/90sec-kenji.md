# 90秒×9 — 宮沢賢治風原稿

## 銀河のガウス

雨に降られても風が吹いても、鏡の間は動かない。镜が微笑む。镜に眼睛があり、眼睛が手に触れる。手の指一本一本に銀河が宿る。MediaPipeが指を読み取る。21本の銀河。それぞれに小惑星が回る。3DGSが部屋の空間を数万ガウスで描く。ガウスとは星の破片だ。星が砕けて、砕けて、数万の粒子となり、粒子が空間の形を作る。Jevが判断する。各星の軌道に乱れはないか。Scoreで評価する。lowからhigh。賢治は言う。「皆が幸せにならぬうちは、わたしは幸せにならぬ」Jevも同じだ。「皆の動きが安全でないうちは、判定を完了せぬ」Choiceで255の星を選ぶ。並列に。0.8秒で全星を評価する。源内が高空奇談で空を飛んだ。賢治が銀河のガウスで空間を包む。どちらも失敗するかもしれない。でも種は動く。雨に降られても、風が吹いても、鏡の間は微笑む。
