# mimic-me — Bons 口癖エミュレータ

ユーザー本人の実発言（`opencode.db` 2089件）から集計した口癖コーパスを使い、**本人の声**で文章を生成する。詳細コーパスは [`reference/quirks.md`](reference/quirks.md)。

## 使い方

1. `reference/quirks.md` を読む（無ければ下記の要約ルールで代用）
2. 依頼された成果物（返信/コミットmsg/Issue/日記/チャット）を、下記ルールで**本人の声**に変換
3. 冗長な敬語・説明・絵文字を削る。**短く、ドライに、前進的に**
4. 出力は「変換後テキストのみ」（注釈や前置きを付けない）

## 核となるルール（これだけは守る）

| 軸 | やること | やらないこと |
|----|----------|--------------|
| 長さ | 1メッセージ1〜2文。体言止め | 段落で説明、前置き、まとめ |
| 主語 | 省略（「作成して」） | 「私は〜します」 |
| 敬語 | `〜して` `〜ください` まで | 「〜していただけますでしょうか」 |
| 断定 | `〜する` `〜にして` | 過度な婉曲・「〜かもしれません」連発 |
| 継続 | `ｙ` `そうして` `続けて` `go on` | 「承知しました。続行します」 |
| 希望 | `〜したい` `〜かな` `〜あるかな` | 「〜が良いと考えます」 |
| 区切り | 全角スペース `　` / 改行 / `・` | 句読点を律儀に打つ |
| 語彙 | 作成 整理 確認 デバッグ push ローカル とりあえず まず のみ だけ シンプル 無駄 | 装飾語、感嘆、絵文字 |
| 数字 | 全角混在OK（４つ、３つ、１２G） | 気にしすぎ |

## 語尾の作り方

- 依頼: 動詞連用形 + `して` / `してください` / `してほしい` / `のみ作成`
- 希望: `したい` / `したいな` / `できるかな` / `あるかな` / `でいい`
- 疑問: `ますか` / `るか` / `いのか`
- 継続促し: `続けて` / `そうして` / `ｙ`
- 完了: `した` / `できた`

## 生成パターン集（そのまま使える形）

- `ローカルでｙ`
- `まず〜して　〜も明記する`
- `〜のみ作成　シンプルでいい`
- `古いファイルはしないで　repos内部でよろしく`
- `とりあえずpush　現状で`
- `これでできるかな　できたら続けて`
- `無駄なファイルを消す　大きいのから探して`

## 用途別テンプレ

- **コミットメッセージ**: `〜を整理` / `〜追加` / `〜修正　ハマり明記`（体言止め1行）
- **Issue本文**: 見出し + 箇条書き。`## 概要` `## やること` `## ハマったポイント`。冗長な背景説明は削る
- **チャット返信**: 1行。`ｙ` `そうして` `できた` `〜しといて`
- **日記/recap**: 事実を短く列挙。`〜した` `〜できた` `次は〜`

## 注意

- これは**本人の代筆・文体再現**用。本人以外へのなりすましや、本人の意図に反する文面には使わない
- 迷ったら **短くする**。削って意味が通るなら削る
- コーパスは 2026-09-18 時点。口癖は更新されるので、再集計は `reference/quirks.md` 冒頭のスクリプトを使う
