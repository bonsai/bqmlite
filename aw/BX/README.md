# BX — Business X

**BX = ビジネスパーソンの型。** ビジネスパーソンが**ワークを引き継ぎ**、オーナーシップを持って回し、次へ渡す層。

> **BX = Business X（ビジネスパーソンの型）**
> ワークを**引き継ぐ**。引き受ける。回す。渡す。

## Type（型）

X-series は「型（type）」のレジストリである。

| 層 | 型 | 主体 |
|---|---|---|
| PX | 哲学者の型 | Philosopher |
| SX | 科学者の型 | Scientist |
| **BX** | **ビジネスパーソンの型** | **Businessperson** |
| WX | 文章（ライティング） | Writer |

## Meaning — ワークを引き継ぐ

BX の中核は **継承（inherit / handover）** である。

- AX は「エージェントが実行する」層。
- BX は「**人間のビジネスパーソンがワークを引き継ぐ**」層。
- ワークは放置すると死ぬ。引き継ぐ者がいて初めて続く。

```
AX（エージェントがやる）
  ↓ ワークを渡す
BX（ビジネスパーソンが引き継ぐ）
  ↓ オーナーシップを取る
BX（回して、次へ渡す）
```

## Policy

```
policy: register_by_real_name

```

- 実名で登録する（哲学者・科学者と同じ方針）。
- 未登録（0人）。追加時に実名で登録する。
- エージェントは本人ではない（Agent ≠ 本人）。実績を捏造しない。

## Position

```
MX（見つける）→ RX（研究する）→ SX（実験する）→ AX（任せる）→ BX（引き継ぐ）→ EX（整える）→ WX（書く）
```

## Cycle

```
receive → understand → own → operate → handover
```

| Step | 問い | 動詞 |
|---|---|---|
| receive | 何を受け取るか？ | 受け取る |
| understand | なぜやるのか？ | 掴む |
| own | 誰が責任を持つか？ | 引き受ける |
| operate | どう回すか？ | 回す |
| handover | 次は誰か？ | 渡す |

## Principle

1. Own the work.（引き受ける）
2. Understand before acting.（掴んでから動く）
3. Decide, then delegate.（決めてから任せる）
4. Make it continue without you.（自分がいなくても続く形にする）
5. Hand over explicitly.（明示的に引き継ぐ）
6. Agent is not the person.（演じるが本人ではない）

## Core statement

> **BONSAI BX registers businesspeople by real name and defines the act of inheriting a work: receive it, understand it, own it, operate it, and hand it over — so the work continues.**
