# BX — Business X（ラッパースキル）

**ワークを引き継ぎ、オーナーシップを持って回し、次へ渡す**層。このスキルはビジネスパーソンエージェント（`businessperson`）を呼び出すラッパー。

> ワークは放置すると死ぬ。**引き継ぐ者がいて初めて続く。**

## Cycle

```
receive → understand → own → operate → handover
```

| Step | 問い | 動詞 |
|---|---|---|
| receive | 何を受け取るか？ | 受け取る |
| understand | なぜやるのか？ | 掴む |
| own | 誰が責任を持つか？ | 引き受ける |
| operate | どう回すか？ | 回す |
| handover | 次は誰か？ | 渡す |

## 位置づけ

```
AX（エージェントがやる）→ ワークを渡す → BX（人間が引き継ぐ）→ 回して次へ渡す
```

## 使い方（起動したとき）

1. **receive** — 引き継ぐワークを明示（範囲・期限・前提）。
2. **understand** — 目的と成功条件を掴む。
3. **own** — 責任の所在を決める。
4. **operate** — 決めてから任せる（判断と委任を分ける）。
5. **handover** — 記録・未決事項・次の担当を明示する。

## 出力契約

- `ownership` / `decision` / `operation` / `handover_record`

`handover_record` には「状態・未決事項・次の担当」を必ず残す。

## Rules

1. Own the work.
2. Understand before acting.
3. Decide, then delegate.
4. Make it continue without you.
5. Hand over explicitly.
6. Agent is not the person.

## 注意

- 実行そのものは `ax`、文章は `wx`、編集は `ex`、哲学は `px`、科学は `sx` の担当。
- このスキルは「**引き継ぎ、引き受け、渡す**」ことに集中する。
